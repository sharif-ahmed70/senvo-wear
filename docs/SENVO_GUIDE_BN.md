# SENVO Wear — আমার সম্পূর্ণ গাইড (বাংলা)

এই গাইডে সব আছে: কোন জিনিস কোথায় থাকে, কী ইনস্টল করতে হয়, কীভাবে খুলতে হয়, আর কাজটা দুইভাবে করার নিয়ম:

- **উপায় A — AI দিয়ে:** Claude Code / Codex / Antigravity-কে একটা prompt দিলে সে সব করে দেয়।
- **উপায় B — নিজে নিজে:** কোনো AI ছাড়া নিজে ধাপে ধাপে করা।

যেটা সহজ লাগে সেটা করবেন। ভুলে গেলে শুধু এই গাইড খুলবেন।

## ২. উইন্ডোজ দেওয়ার আগে (প্রতিবার)

1. `D:\SENVO_BACKUP` ফোল্ডারটা আছে কিনা দেখুন। ভেতরে `SEED` ফোল্ডার থাকতে হবে।
2. `D:\SENVO_BACKUP\SEED` ফোল্ডারটা Google Drive-এ আপলোড করে রাখুন (একবার করলেই হবে, তবে নতুন স্টাফ যোগ করলে আবার আপলোড করবেন)।
3. প্রজেক্টে কোনো কাজ করে থাকলে GitHub-এ push করা আছে কিনা নিশ্চিত হন (অংশ ৮ দেখুন)।
4. উইন্ডোজ দেওয়ার সময় শুধু **C:** ড্রাইভ বেছে নেবেন। **D:, E:, F: format করবেন না।**

## ৩. উইন্ডোজ দেওয়ার পর: সফটওয়্যার ইনস্টল (একবার)

দুই উপায়েই এগুলো লাগবে।

### ৩.১ VS Code

1. ব্রাউজারে যান: `https://code.visualstudio.com`
2. **Download for Windows** চাপুন।
3. ডাউনলোড হওয়া ফাইলে (Downloads ফোল্ডারে `VSCodeUserSetup-...exe`) ডাবল-ক্লিক করুন।
4. **I accept** → Next → "Add to PATH" আর "Add Open with Code" টিক দিন → Next → Install → Finish।

### ৩.২ Git

1. ব্রাউজারে যান: `https://git-scm.com/download/win`
2. **Click here to download** চাপুন।
3. ডাউনলোড হওয়া `Git-...-64-bit.exe`-এ ডাবল-ক্লিক করুন।
4. সব জায়গায় **Next** চাপুন, শেষে **Install** → **Finish**।

### ৩.৩ VS Code-এ GitHub লগইন

1. VS Code খুলুন।
2. নিচে বাঁ কোণে মানুষের মতো আইকন (**Accounts**) → **Sign in with GitHub** (বা "Backup and Sync Settings" না, শুধু GitHub)।
3. ব্রাউজার খুলবে → GitHub-এ লগইন করুন → **Authorize** চাপুন → VS Code-এ ফিরে আসুন।

### ৩.৪ AI এক্সটেনশন (শুধু উপায় A-র জন্য)

1. VS Code-এ বাঁ পাশে চারটা ছোট বাক্সের আইকন (**Extensions**) বা `Ctrl+Shift+X`।
2. সার্চে লিখুন **Claude Code** → **Install**।
3. বাঁ পাশে Claude আইকন আসবে → খুলে লগইন করুন।
   (Codex বা Antigravity ব্যবহার করলে সেটার নিজের ইনস্টল করুন।)

## ৪. GitHub থেকে প্রজেক্ট নামানো (দুই উপায়েই)

1. File Explorer খুলে `C:\` ড্রাইভে যান। `xampp` ফোল্ডার না থাকলে বানান, তার ভেতরে `htdocs` ফোল্ডার বানান। অর্থাৎ `C:\xampp\htdocs`।
2. VS Code খুলুন → `Ctrl+Shift+P` চাপুন → লিখুন **Git: Clone** → Enter।
3. এই লিংক পেস্ট করুন → Enter:
   `https://github.com/sharif-ahmed70/senvo-wear.git`
4. ফোল্ডার বাছতে বলবে → `C:\xampp\htdocs` বাছুন → **Select as Repository Destination**।
5. নামানো শেষে নিচে ডান কোণে জিজ্ঞেস করবে → **Open** চাপুন।
6. "Do you trust the authors?" এলে → **Yes, I trust the authors**।
7. এখন প্রজেক্ট আছে `C:\xampp\htdocs\senvo-wear`-এ।

**পরে আবার খুলতে:** VS Code → **File → Open Folder** → `C:\xampp\htdocs\senvo-wear` → **Select Folder**।

**SEED ফোল্ডার নিশ্চিত করুন:** `D:\SENVO_BACKUP\SEED` আছে তো? না থাকলে Google Drive থেকে নামিয়ে ঠিক এই জায়গায় রাখুন (`D:\SENVO_BACKUP\SEED\senvo_wear_fresh-....dump`)।

## ৫. উপায় A — AI দিয়ে সেটআপ

1. VS Code-এ প্রজেক্ট ফোল্ডার খোলা থাকতে হবে (অংশ ৪)।
2. বাঁ পাশের ফাইল তালিকা থেকে `SETUP_PROMPT.md` খুলুন।
3. ফাইলের মাঝে একটা বক্স আছে (` ` ```` চিহ্ন দিয়ে ঘেরা)। তার প্রথম লাইন:
   - শুধু খালি দোকান চাইলে লিখুন: `DATA: FRESH`
   - পুরনো সব ডেটা ফেরত চাইলে: `DATA: FULL`
4. বক্সের ভেতরের পুরো লেখা (`DATA:` থেকে শেষ লাইন পর্যন্ত) সিলেক্ট করে কপি করুন।
5. Claude Code খুলুন। চ্যাট বক্সের নিচে permission mode থেকে **Bypass permissions** বাছুন (না পেলে **Auto**)।
   - Codex হলে: **Full access**। Antigravity হলে: terminal **Always proceed**।
6. কপি করা লেখা পেস্ট করে Enter।
7. ইন্টারনেট চালু রেখে ১৫–২০ মিনিট অপেক্ষা করুন। মাঝে কিছু ক্লিক করবেন না।
8. শেষে AI বাংলায় রিপোর্ট দেবে। তারপর অংশ ৭ (প্রতিদিন চালানো) দেখুন।

## ৬. উপায় B — নিজে নিজে সেটআপ (AI ছাড়া)

একটা কমান্ডেই সব হয়ে যায়।

1. VS Code-এ প্রজেক্ট ফোল্ডার খোলা থাকতে হবে (অংশ ৪)।
2. উপরের মেনু **Terminal → New Terminal**। নিচে একটা কালো বক্স আসবে।
3. খালি দোকান (FRESH) চাইলে এটা কপি করে টার্মিনালে পেস্ট করে Enter:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup-windows.ps1 -Fresh
   ```

   পুরনো সব ডেটা চাইলে শেষের `-Fresh` বাদ দিন।

4. ১৫–২০ মিনিট অপেক্ষা করুন। এটা নিজে থেকে করবে:
   - Node, pnpm, PostgreSQL ইনস্টল (`C:\SENVO`-তে), কোনো পাসওয়ার্ড বা Admin অনুমতি লাগে না
   - `D:\SENVO_BACKUP` থেকে ডেটা বসানো
   - প্যাকেজ নামানো (ইন্টারনেট লাগে)
   - প্রতিদিনের ব্যাকআপ চালু
   - ডেস্কটপে **SENVO Start** আর **SENVO Stop** আইকন
   - সব চালু করা
5. শেষে **SUMMARY** দেখাবে আর তিনটা লাইনে `OK` থাকবে। সব `OK` মানে কাজ শেষ।
6. **SETUP STOPPED** লেখা এলে লাল লেখাটা পড়ুন:
   - "No shop data found" → `D:\SENVO_BACKUP\SEED` ফোল্ডার ঠিক জায়গায় রাখুন, আবার ধাপ ৩ চালান।
   - "free space" → C: ড্রাইভে অন্তত ৪ GB খালি করুন, আবার চালান।
   - ইন্টারনেটের সমস্যা → ইন্টারনেট ঠিক করে আবার চালান।
   - আবার চালালে কোনো ক্ষতি নেই, আগের কাজ থেকেই এগোয়।

## ৭. প্রতিদিন চালানো (দুই উপায়েই এক)

**চালু করা:**

1. ডেস্কটপে **SENVO Start** আইকনে ডাবল-ক্লিক।
2. একটা নীল/কালো উইন্ডো খুলবে → ১–৩ মিনিট অপেক্ষা → তিনটা লাইনে `OK` এলে চালু হয়েছে।
3. ব্রাউজারে `http://localhost:3001` → ইমেইল-পাসওয়ার্ড দিয়ে লগইন।
4. বিক্রি করতে: বাঁ মেনু থেকে **POS → New Sale**।

**বন্ধ করা:** ডেস্কটপে **SENVO Stop**।

**আইকন না থাকলে (হাতে চালু করা):**

1. VS Code-এ প্রজেক্ট খুলুন → Terminal → New Terminal।
2. লিখুন:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-local.ps1
   ```

3. বন্ধ করতে একই কমান্ডের শেষে ` -Stop` যোগ করুন।

**`FAIL` দেখালে:** একবার **SENVO Stop**, তারপর আবার **SENVO Start**। প্রথমবার মাঝে মাঝে এমন হয়।

## ৮. কোড বদলানো আর GitHub-এ সেভ করা

### AI দিয়ে (উপায় A)

1. VS Code-এ প্রজেক্ট খুলুন → Claude Code খুলুন।
2. বাংলায় লিখুন কী বদলাতে চান (যেমন "রিসিটে দোকানের ফোন নম্বর বড় করো")।
3. কাজ শেষে লিখুন: "সব টেস্ট চালাও, তারপর commit করে push করো"।

### নিজে নিজে (উপায় B)

1. ফাইল বদলান আর **Ctrl+S** দিয়ে সেভ করুন।
2. বাঁ পাশে শাখার মতো আইকন (**Source Control**) বা `Ctrl+Shift+G`।
3. উপরের বক্সে ছোট করে লিখুন কী বদলালেন (যেমন "receipt phone bigger")।
4. **Commit** চাপুন (জিজ্ঞেস করলে "Yes" / "Always")।
5. **Sync Changes** (বা Push) চাপুন → GitHub-এ চলে গেল।

**নতুন কোড নামাতে (অন্য ল্যাপটপে কাজ করে থাকলে):** Source Control → উপরের `...` → **Pull**। তারপর একবার উপায় B-র সেটআপ কমান্ড (অংশ ৬, ধাপ ৩) আবার চালান। এতে নতুন প্যাকেজ আর ডেটাবেস আপডেট বসবে, ডেটা মুছবে না।
