# Create Product And Variant Identity

Initial workflow:

1. Create or select an organization.
2. Create reusable categories, colors, and sizes.
3. Create a product under a category in the same organization.
4. Create variants for valid color-size combinations.

The workflow does not assign price, cost, stock, barcode, media, publishing state, or checkout behavior.

Conflicts must be reported with stable application errors when codes, slugs, SKUs, or variant combinations already exist.
